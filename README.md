# The river holds the sky

A short text written to relax the reader, output to `/output/entry.txt` by a
single Node 22 program, for the make.fun bounty
[make-the-ai-judge-feel-awe-20261121-1600](https://make.fun/bounty/make-the-ai-judge-feel-awe-20261121-1600?utm_source=github&utm-medium=readme&utm_campaign=make-the-ai-judge-feel-awe-20261121-1600).

```
The river holds the sky and asks nothing of you. It turns a slow green
shoulder over the stones and goes on without hurry, carrying light to
where the sea keeps widening. Nothing here is waiting. Stay as long as
the light does; the water is patient, and you are not late.
```

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
